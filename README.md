# game_shy_ — NEON BREAKER

의존성 없는 캔버스 벽돌깨기. 빌드 도구도, 외부 라이브러리도, 에셋 파일도 없다.
`index.html` 을 브라우저로 열면 바로 실행된다.

![플레이 화면](docs/gameplay.png)

## 실행

```bash
# 1) 그냥 파일을 연다 — 이것만으로 충분하다
open index.html          # macOS   (Windows: start / Linux: xdg-open)

# 2) 로컬 서버로 띄우고 싶다면
npm start                # http://localhost:8080
```

## 조작

| 동작 | 키 |
| --- | --- |
| 패들 이동 | 마우스 · 터치 드래그 · `←` `→` · `A` `D` |
| 발사 / 레이저 | `Space` · 화면 탭 |
| 일시정지 | `P` · `Esc` |
| 음소거 | `M` |

## 규칙

- 목숨 3개로 시작해 8개 레벨을 돌파한다. 공을 전부 놓치면 목숨이 하나 줄어든다.
- **콤보**: 패들에 닿지 않고 벽돌을 연달아 부수면 배수가 오른다(최대 x5). 패들에 닿는 순간 초기화.
- 패들 **어디에** 맞히느냐로 반사각이 정해진다. 가장자리일수록 크게 꺾인다.
  패들을 옆으로 밀면서 받으면 그만큼 공이 옆으로 실린다.
- 벽돌 색은 내구도다. 1히트 벽돌은 행마다 색이 다르고, **노랑 = 2히트**, **빨강 = 3히트**,
  **회색(빗금) = 파괴 불가**. `?` 벽돌은 아이템을 반드시 떨군다.

## 아이템

떨어지는 아이템을 패들로 받으면 발동한다. **빨간 테두리는 함정이다.**

| | 이름 | 효과 |
| --- | --- | --- |
| `3x` | 멀티볼 | 공이 3배로 갈라진다 |
| `W+` | 확장 | 패들이 넓어진다 (20초) |
| `LZR` | 레이저 | `Space` 로 벽돌을 쏜다 (14초) |
| `GLU` | 끈끈이 | 공이 패들에 붙는다. 원하는 각도로 다시 발사 (15초) |
| `SLO` | 감속 | 공이 느려진다 (12초) |
| `500` | 보너스 | +500점 |
| `1UP` | 목숨 | 목숨 +1 |
| `W-` | **축소** | 패들이 좁아진다 (12초) |
| `FST` | **가속** | 공이 빨라진다 (10초) |

## 구조

```
index.html          캔버스 한 장과 스크립트 로드
css/style.css       캔버스를 화면에 맞추는 레이아웃만
js/audio.js         WebAudio 로 즉석 합성하는 효과음 (에셋 없음)
js/input.js         키보드 / 마우스 / 터치 입력 정규화
js/particles.js     고정 크기 풀을 돌려 쓰는 파티클 + 점수 텍스트
js/levels.js        레벨 지도 데이터 + 검증
js/entities.js      상수, 패들 / 공 / 벽돌 / 아이템, 원-사각형 충돌
js/game.js          상태 기계, 물리, 렌더링
js/main.js          부팅 + 고정 스텝 루프
test/               레벨 검증 + 브라우저 스모크 테스트
```

ES 모듈 대신 전역 `NB` 네임스페이스를 쓴다. `file://` 로 열었을 때 CORS 에 막히지 않게
하기 위한 선택이다.

물리는 화면 주사율과 무관하게 항상 1/60초 고정 스텝으로 돈다. 120Hz 모니터에서
공이 두 배로 빨라지지 않는다.

## 레벨 추가하기

`js/levels.js` 의 `levels` 배열에 항목을 하나 더한다. 지도는 **한 줄이 정확히 10글자**여야 한다.

```
.  빈칸      1  일반(1히트)   2  단단(2히트)   3  강철(3히트)
X  파괴 불가(클리어 조건에서 제외)          P  아이템 확정(1히트)
```

```js
{
  name: 'MY LEVEL',
  speed: 7.0,          // 이 레벨의 공 속도
  map: [
    '1111111111',
    '..2P22P2..',
    'X33333333X'
  ]
}
```

지도를 고쳤으면 검증부터 돌린다. 행 길이가 어긋나거나 모르는 글자가 있으면 잡아 준다.

```bash
npm test
```

## 테스트

```bash
npm test              # 레벨 데이터 검증 — 의존성 없음
npm i                 # 브라우저 테스트용 playwright 설치
npm run test:browser  # 실제 크로미움에서 게임을 돌려 24개 항목 검사
```

브라우저 테스트는 로드 에러, 발사/물리, 공이 벽을 뚫지 않는지, 패들이 벽 안에 갇히는지,
아이템 9종 전부, 일시정지, 8레벨 클리어 전이, 목숨 소진, 하이스코어 저장까지 확인한다.
`SHOTS=./shots` 를 붙이면 단계별 스크린샷을 남긴다.

시스템에 설치된 다른 크로미움을 쓰려면 `PW_CHROME=/path/to/chrome` 으로 지정한다.
